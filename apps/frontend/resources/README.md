# 📱 Ressources pour l'application mobile

## 🎨 Instructions pour les icônes

### **Icon.png** (1024x1024px)
- Copiez votre logo `Logo ATW Humanitae.png` ici
- Renommez-le en `icon.png`
- Taille recommandée : **1024x1024 pixels**
- Format : PNG avec fond transparent ou fond de couleur

### **Splash.png** (2732x2732px)
- Image d'écran de démarrage
- Taille recommandée : **2732x2732 pixels**
- Le logo doit être centré avec un fond de couleur ATW (#1E3A8A)

## 🔧 Génération automatique des icônes

Une fois les fichiers en place, exécutez :
```bash
npm run resources
```

Cela générera automatiquement toutes les tailles d'icônes nécessaires pour Android.
